# 第三轮：字母融合与图形探索

笑脸是上一轮的举例。这一轮扩大形状范围，探索字母、负空间和结构本身的识别度，编号为 **25—36**。

- [浅色总览](overview.png) · [深色总览](overview-dark.png)
- [单色轮廓对比](shapes.png)：统一颜色，先比较形状。
- [交互选型页](gallery.html)：支持深浅背景、收藏、复制编号、16／24／32 px 比较和素材下载。
- [第一轮 01—12](../README.md) · [第二轮 13—24](../round-2/README.md)

| 编号 | 名称 | 设计方向 |
| --- | --- | --- |
| [25](icons/25.svg) | 字母建筑 | 大 D 线框，内部明确保留 iLi，统一字母基线。 |
| [26](icons/26.svg) | 刻进 D 里 | D 色块中用透明负空间刻出 iLi，像一枚名字印章。 |
| [27](icons/27.svg) | 拼写 D | i、L 和右侧半圆直接参与构造 D，不再在内部放小字。 |
| [28](icons/28.svg) | 回廊 | 大 D 内部的 L 路径和短竖块，像工作台布局。 |
| [29](icons/29.svg) | 折带 | 宽折带与折面构造 D，偏几何感。 |
| [30](icons/30.svg) | 相扣 | 竖向 L 和圆弧连结成 D，笔画少、轮廓直接。 |
| [31](icons/31.svg) | 像素门 | 网格 D 和门形留白，偏开发工具。 |
| [32](icons/32.svg) | 双轨 D | 两条等宽轨道围绕 D 并行，表达上下文延续。 |
| [33](icons/33.svg) | 交汇 | 两个半圆向中间靠近，以一枚方块连接。 |
| [34](icons/34.svg) | 书签接力 | 两枚反向书签交叠，表达记录与交接。 |
| [35](icons/35.svg) | 四向工作 | 四块几何形向中心收拢，中心保留菱形空间。 |
| [36](icons/36.svg) | 嘀哩节拍 | 三枚高低不同的竖块，呼应名字的节奏。 |

建议先比较 **26、27、29、35**。26 更贴近 D + iLi；27 把字母作为整体结构；29 更像一个独立的几何标志；35 则从多个会话共同工作出发。

25、26 有更完整的字母信息，缩小时需要仔细比较内部细节；29、30、35 的轮廓更简练。深色版本对部分标志调亮颜色，单色版用于比较形状。26 的字母镂空使用 SVG mask，PNG 同样保留透明度。

## 素材与生成

- `icons/`、`icons-dark/`：浅色底与深色底的透明图标 SVG，画板 100×100。
- `mono/`：单色 SVG；28 的内部字形使用白色。
- `25.svg` 至 `36.svg`、`dark/`：浅色和深色背景横版组合。
- `png/`：512×512 RGBA PNG。
- `concepts.json`：编号、设计说明、标语、配色。
- `generate.py`：素材与选型页生成源文件，复用第二轮的 SVG 字标和第一轮的选型页样式与交互。

执行 `python3 docs/logo-concepts/round-3/generate.py` 生成 SVG 和 HTML；加 `--render` 导出 PNG 与总览。渲染依赖系统的 PyGObject/Rsvg、pycairo、Pillow、Noto Sans CJK 和 DejaVu Sans 字体，不修改应用依赖。

素材已保存用于选择，应用仍使用当前 Logo。
