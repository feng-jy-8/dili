# Dili Logo 设计候选

为 Dili（嘀哩工作台）设计的 12 个视觉方向。**已选用 02「开口 d / Open D」作为正式 Logo**，其余方向保留作为设计记录。

打开 [交互选型页](gallery.html)，可切换浅色／深色背景、收藏方案、比较 16／24／32 px 小尺寸效果，并下载素材。收藏保存在当前浏览器中。也可直接查看 [浅色总览](overview.png) 和 [深色总览](overview-dark.png)。

## 方案

| 编号 | 名称 | 设计思路 |
| --- | --- | --- |
| [01](icons/01.svg) | 嘀一下 / Pulse Bubble | 用一笔短促的脉冲，把“嘀”的声音变成正在回应的会话。 |
| [02](icons/02.svg) | 开口 d / Open D | 小写 d 的开口是会话的入口；一颗亮点，让沉稳的轮廓有了记忆点。 |
| [03](icons/03.svg) | 嘀哩小脸 / Dili Face | 一张有点机灵的小脸，带着 d 字形的耳朵；工作台也可以有亲近感。 |
| [04](icons/04.svg) | 并肩双豆 / Side by Side | 两颗朝向彼此的圆豆，各有自己的轮廓，围绕共同任务靠近。 |
| [05](icons/05.svg) | 随行桥 / Relay Bridge | 两个端点之间是一道有力的拱桥，表达本地与远程之间稳定的连接。 |
| [06](icons/06.svg) | 灵感回声 / Spark Reply | 对话气泡里藏着一枚斜切的火花，适合强调把想法推进成结果。 |
| [07](icons/07.svg) | 一格工作台 / Workbench | 简练的工作台分栏，亮起的一格代表正在工作的会话。 |
| [08](icons/08.svg) | 一触即发 / Prompt Tile | 大比例提示符搭配光标，轮廓直接、醒目，适合偏开发工具的定位。 |
| [09](icons/09.svg) | 双声道 / Double Voice | 两条相互呼应的 d 形声道，借用“嘀哩”的节奏形成连续图形。 |
| [10](icons/10.svg) | 不断线 / Context Ribbon | 连续折带构成一枚 d；转折仍然相连，呼应 Fork 与跨模型延续。 |
| [11](icons/11.svg) | 会话向导 / Conversation Compass | 一枚简洁的方向针嵌在对话轮廓里，强调会话始终围绕任务展开。 |
| [12](icons/12.svg) | 会话积木 / Session Blocks | 四块错落的圆角积木组成动态 d，让多个会话的状态一眼可辨。 |

02「开口 d」已应用到侧边栏、登录页、共享会话、会话空白页、浏览器 favicon 和安装图标。正式横版组合使用“嘀哩工作台”作为副标题，候选素材中的“OPEN D”保留为方案名。

## 素材结构

- `icons/`：100×100 应用图标 SVG。
- `png/`：512×512 图标 PNG。
- `marks/`：透明背景的白色／强调色标志，适用于深色底。
- `mono/`：单色 SVG，适用于简化印刷或单色界面。
- `01.svg` 至 `12.svg`：浅色背景横版组合，包含矢量字标。
- `dark/`：深色背景横版组合。
- `concepts.json`：编号、名称、描述、标语和配色。

正式素材位于 `public/logo.svg`、`public/icon.svg`、`public/favicon.svg` 和 `public/icon-maskable.svg`。候选目录保留原始设计，浅色／深色总览是选型时的静态记录。
