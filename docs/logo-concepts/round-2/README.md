# 第二轮：大 D 与 iLi 笑脸

这一轮围绕“大 D 作为外轮廓，iLi 作为内部笑脸”展开，编号延续第一轮，为 **13—24**。

- [浅色总览](overview.png) · [深色总览](overview-dark.png)
- [交互选型页](gallery.html)：用浏览器打开，支持深浅色切换、收藏、复制编号和下载。
- [字形拆解](anatomy.svg)：D 外轮廓 + 两个 i + 弯折的 L。
- [第一轮方案](../README.md)

| 编号 | 名称 | 变化重点 |
| --- | --- | --- |

建议先看 **13、15、16、18**。13 最能说明 D + iLi，15 更适合应用图标，16 更有性格，18 的表情更直观。

字母可读性和表情自然度存在取舍：完整的 i 需要圆点和竖笔，L 则容易被读成鼻子；简化五官后更像笑脸，但 iLi 会更含蓄。16、24 px 的效果可以在总览和选型页直接比较。

## 文件

- `icons/`：透明背景图标 SVG，画板为 100×100。
- `icons-dark/`：深色背景图标 SVG；14、18、21 提高了线条亮度。
- `mono/`：单色版本，实心形状中的五官使用白色。
- `13.svg` 至 `24.svg`：浅色底横版组合；`dark/` 为深色底组合。
- `png/`：512×512 RGBA PNG。
- `concepts.json`：编号、名称、设计说明、标语与配色。
- `generate.py`：SVG、HTML 和 PNG 的生成源文件。

运行 `python3 docs/logo-concepts/round-2/generate.py` 可重新生成 SVG 和选型页。加 `--render` 会重新导出 PNG 和总览图；该选项需要系统的 PyGObject/Rsvg、pycairo、Pillow，以及 Noto Sans CJK 和 DejaVu Sans 字体。生成过程不需要安装或修改应用依赖。

这轮是供选择的设计素材，尚未替换应用中的 Logo。
